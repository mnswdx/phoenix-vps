# 🔥 Phoenix: Zero-Touch Disaster Recovery for VPS & Xray

**Phoenix** — это автономное Infrastructure-as-Code (IaC) решение для создания зашифрованных резервных копий и мгновенного развёртывания VPS-сервера с VLESS + REALITY (3x-ui / Xray) за 60 секунд.

---

## 🎯 Что решает Phoenix?

В случае блокировки IP-адреса хостинга, физической аварии дата-центра или удаления инстанса:
1. **Никакой рутины:** Не нужно заново 40 минут вручную настраивать BBR, Swap, UFW, Fail2ban и 3x-ui.
2. **Бесшовное переключение:** Не нужно перевыпускать ключи, QR-коды и перенастраивать клиенты (ПК, смартфон, устройства семьи) — восстанавливается точная копия базы данных клиентов (`x-ui.db`). В приложениях достаточно изменить лишь IP-адрес нового сервера.

---

## 🛡️ Безопасность данных

* База данных 3x-ui, сетевые настройки и правила файрвола упаковываются в защищённый архив и шифруются алгоритмом **AES-256-CBC** с функцией вывода ключа **PBKDF2 (100 000 итераций)**.
* Без вашего мастер-пароля расшифровать файл математически невозможно.
* Все файлы архивов (`*.enc`, `*.tar.gz`, `*.db`) изолированы через `.gitignore`.

## 📋 Пошаговый сценарий (Runbook)

### Шаг 1: Создание бэкапа на действующем сервере

Подключитесь к вашему текущему серверу по SSH и запустите:

```bash
curl -sL https://raw.githubusercontent.com/mnswdx/phoenix-vps/main/backup.sh | bash
```

1. Скрипт попросит ввести и подтвердить **пароль шифрования**.
2. В результате будет сформирован зашифрованный файл: `/root/phoenix_backup_ГГГГММДД_ЧЧММСС.enc`.

---

### Шаг 2: Сохранение бэкапа на локальный компьютер

В терминале вашего ПК (PowerShell для Windows или bash для Linux/macOS) скачайте бэкап:

```powershell
scp root@<IP_СЕРВЕРА>:/root/phoenix_backup_*.enc ./
```

---

### Шаг 3: «День X» — Восстановление из пепла за 60 секунд

При покупке нового чистого сервера (Ubuntu 22.04 / 24.04 или Debian 12):

1. Загрузите бэкап на новый сервер:
   ```powershell
   scp phoenix_backup_*.enc root@<НОВЫЙ_IP>:/root/backup.enc
   ```

2. Подключитесь к новому серверу:
   ```bash
   ssh root@<НОВЫЙ_IP>
   ```

3. Запустите автоматическое восстановление:
   ```bash
   curl -sL https://raw.githubusercontent.com/mnswdx/phoenix-vps/main/deploy.sh | bash -s -- /root/backup.enc
   ```

4. Введите пароль расшифровки. Скрипт автоматически:
   - Обновит систему и установит нужные пакеты;
   - Включит оптимизацию TCP **Google BBR**;
   - Создаст и подключит **Swap 1 GB** (`vm.swappiness = 10`);
   - Запустит защиту от брутфорса **Fail2ban**;
   - Заблокирует лишние порты через **UFW** (открыты только `22` и `443`);
   - Установит панель **3x-ui** и накатит базу данных клиентов.

Все ваши устройства продолжат работать по старым ключам!
